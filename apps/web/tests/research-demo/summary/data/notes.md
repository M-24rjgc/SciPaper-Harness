# 评测笔记

- 语料：200 篇长文（新闻特稿和机构报告），每个系统每篇生成一段摘要。
- 三个系统：lead-3（抽取式基线）、bart-large（抽象式）、bart-large-rl（加了一致性奖励的强化学习微调）。
- 长度分档：按摘要模型的分词器计 token，短（3k 以下）70 篇、中（3k 到 6k）70 篇、长（6k 以上）60 篇。
- 人工标注：每篇摘要由两名标注者判断是否与原文一致，分歧由第三人裁决；表里是裁决后被判为一致的比例。正式标注前先用语料外的一小批摘要做了校准。
- 自动指标：SummaC（基于 NLI，卷积版，默认设置）和 QAFactEval（基于问答，官方配置），都读全文，不截断。
- 观察：两个自动指标给出的系统排序与人工一致，每个长度档都一致；但分数和人工一致率不在同一个尺度上，不能直接比大小。
- 摘要级别用 AUC 看指标能不能区分一致和不一致的摘要：SummaC 在长文档上掉得明显，QAFactEval 比较稳。长档只有 60 篇，这个差别要谨慎说。
