# Synthetic data / 合成数据

The six values in `results.csv` are authored synthetic demonstration data. No generated summaries were annotated and no participants were recruited. `seed` identifies paired illustrative rows, not executed model runs. `consistency_percent` is an illustrative percentage on a 0–100 scale.

Baseline mean consistency is 87%; evidence-grounded mean consistency is 91%. Both sample standard deviations equal one percentage point. Each paired difference is four percentage points. The paired differences have no sampling uncertainty because the values were authored; they cannot justify a significance test.

六个数值均为编写的合成演示数据，没有摘要人工标注或受试者参与。`seed` 表示演示行的配对，不是实际模型运行。`consistency_percent` 是 0 到 100 的演示百分比。普通方法均值为 87%，基于证据的方法为 91%，样本标准差均为 1 个百分点；每对相差 4 个百分点。由于数值是编写的，配对差异不具有抽样不确定性，不能据此进行显著性检验。
