# 评测设计

## 问题与机制

候选机制根据查询与键的内容为注意力块打分，在固定预算内保留得分最高的块。假设是：把同样的预算分配给相关块，相比固定几何模式，能减少任务准确率损失。

## 匹配比较

稠密注意力作为准确率参照。固定稀疏注意力与内容自适应注意力都保留 25% 的条目。真实评测需固定骨干网络、分词器、序列长度、训练数据、优化器、训练步数和种子。选择器的额外计算需计入端到端延迟和峰值显存。

## 结论对应的检验

1. 相同保留比例下的准确率比较，检验预算分配假设。
2. 同预算的随机选择器，区分内容选择与稀疏本身的作用。
3. 预算扫描，检验效果是否只存在于一个保留比例。
4. 端到端延迟与峰值显存，检验包含选择器开销后的计算收益。

随附 CSV 仅用合成数据说明第一项比较，不为其余三项结论提供证据。置信区间和显著性结论需要真实重复观测及适当的抽样设计。
