# 使用 Web UI

[English](index.md) | 中文

请先按照[根目录 README](../../../README.zh.md#run) 中的说明启动 Web UI；命令会打印其访问地址。本指南从服务器已经运行的状态开始。`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的 Web UI 则不会选中任何工作区，你需要添加一个工作区。

## 配置模型

打开**设置 → 模型**，输入 [DeepSeek API 密钥](https://platform.deepseek.com/)并保存。模型路由会立即可用，不需要重启服务器。

[模型配置指南](./providers.zh.md)介绍其他提供方和自定义 OpenAI 兼容端点。

## 选择工作区

点击**选择工作区**，添加启动 `dsh` 时所在的项目目录，然后选中它。选中工作区前，会话输入框不可用。

## 通过 SSH 在远端机器上工作

在研究侧栏中，点击**研究**旁的**＋**，选择**添加 SSH 工作区**。远端机器需要运行 Linux 或 macOS，并安装 Node.js 22 或更新版本。填写：

- **主机**：`~/.ssh/config` 中的别名，或 `用户@主机`。
- **端口**（可选）：留空表示 22。
- **远端绝对路径**：远端机器上的项目目录。
- **登录方式**：**密钥或 ssh 配置（默认）**与 `ssh` 命令完全一样，使用你的 ssh 密钥、认证代理和 `~/.ssh/config`。**密码**用你填写的用户名和密码登录，不需要密钥，也不需要任何 ssh 配置。

无论哪种登录方式，首次添加本机从未连接过的主机时，对话框都会显示**信任这台主机吗？**，并列出服务器的密钥类型和 SHA256 指纹。请把指纹与服务器管理员提供的指纹对照，例如在服务器上运行 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 得到的结果。只有两者一致才点击**信任并继续**：密钥随后会保存到你的 `~/.ssh/known_hosts`（`ssh` 读取的同一个文件），连接继续进行。点**不信任**则不保存任何内容。主机的密钥与之前保存的不同时，会被拒绝，且不提供信任选项。如果对话框没有显示指纹（例如主机要经过代理才能到达），请在终端里运行一次 `ssh 用户@主机` 并输入 `yes`。

密码会先向主机验证，只有主机接受才会保存。它保存在本机你的用户配置目录里，与 API 密钥在同一个凭据文件中；它没有加密，能读取你用户配置目录的人都能读到它。移除某主机上的最后一个工作区会删除它保存的密码，用**密钥或 ssh 配置**重新添加该工作区也会忘掉它。该工作区上各项研究的远程实验使用同一个密码登录。

主机无法使用时，对话框会说明原因：登录被拒绝、连不上主机、主机密钥已变更，或本机的 OpenSSH 低于密码登录所需的 8.4 版本。

## 运行任务

启动一个会话并发送：

> Summarize this repository and identify its main packages.

Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。
